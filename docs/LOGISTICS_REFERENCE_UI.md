# Logistics reference interface

Open **Screening → Logistics** in the local application. This increment implements the supplied two-panel Logistics design over a cached illustrative lunar background. It keeps the existing 20-input LCSS model separate from the published NASA water-ISRU reference case.

## Delivered

- LCSS heading and exploratory badge, A/B selection, four-crew/730-day duration, hypothetical ice input with stepper and keyboard-accessible slider, shared planning budget, calculated stacked mass bar and legend, subtotal and budget status, tested budget-fit search, and the complete set of 20 editable architecture inputs.
- A live preview appears immediately using the current assumptions. Merely opening the page does not enable report inclusion or modify either scenario. The explicit **Include exploratory results in export** checkbox retains the existing enable/disable behavior. Hypothetical ice remains independent for A and B; architecture inputs and planning budget remain shared. Editing invalid assumptions preserves the prior valid model state.
- The bar accounts for all calculated mass: life-support hardware, extraction equipment, power generation plus storage, dry-system spares, and Earth-supplied water. Exact values remain available under the bar and in the detailed accounting disclosure, including contributors too narrow for a readable label. The reference image's illustrative contributor values are not inserted. At the existing defaults the actual subtotal is 21,670 kg: 8,000 kg hardware, 1,250 kg extraction, 10,250 kg energy/storage, 1,950 kg spares and 220 kg Earth-supplied water.
- The budget-fit action uses the existing 61-sample, 0–6 wt% concentration search. Its proposal leaves the current assumptions unchanged until **Apply tested assumption** is selected. Changes to inputs or active scenario clear the rendered proposal. No-fit results retain supported/unsupported sample counts. No concentration is presented as a local measurement or resource discovery.
- The NASA panel uses the existing checked source: 225 production days, 4,900 kg printed hardware subtotal, 68 kW demand, and 15,000 kg water. It displays the assumed 5 wt% concentration, 23 published source values, seven bookkeeping checks and the pinned Kleinhenz/Paz NASA NTRS PDF link. The mining/transport/processing illustration is a presentation diagram, not a selected equipment design.
- Study exclusions, all source values and check details, the printed-precision mass residual, LCSS accounting boundaries, A/B comparison, ice evidence/context, and engineering evidence/acceptance gates remain accessible in disclosures. Disclosures remain open while values are edited. The full 20-input architecture is still uncalibrated; the NASA reference does not supply equipment or local ice calibration for it.
- Responsive desktop cards and stacked tablet/mobile cards, with scrollable Screening subtabs. The cinematic background uses a cached 1600×960 render and a separate preview preset; it does not introduce another interactive renderer or change scientific inputs. The classic interface remains available with its existing presentation.

The selected short Sun/Earth assessment window does not determine the independent 730-day operating duty or storage assumptions. No environmental verdict, accepted logistics score, operational power availability, safe landing decision or scientific/engineering acceptance is inferred from the presentation.
