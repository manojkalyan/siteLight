1. Problem Statement
Mission planners at the lunar south pole must jointly satisfy power generation (solar elevation and duration) and direct-to-Earth communication (Earth visibility above the local terrain horizon) for a candidate site–date pair. When launch dates slip or hardware constraints change, planners must rapidly re-evaluate alternatives. Existing tools—NASA QuickMap, Moon Trek, JPL Horizons—are built for detailed analysis and require navigating multiple interfaces and interpreting raw outputs. The result is a replanning bottleneck: planners can see that a site–date combination fails, but not which constraint is binding, by how much, or what change would make it viable.

SiteLight AI closes this gap with a causal, interactive comparison tool.
